# Architecture & Technical Overview

**We All Breathe the Same Air** (*Like Dust Part 2*) is an interactive digital video graphic novel designed for seamless delivery across **Web browsers**, **Apple iOS**, and **Google Android**.

```
                           ┌────────────────────────┐
                           │    Single Codebase     │
                           │   (HTML5, Canvas,      │
                           │   Three.js, WebGL)     │
                           └───────────┬────────────┘
                                       │
            ┌──────────────────────────┼──────────────────────────┐
            ▼                          ▼                          ▼
   ┌─────────────────┐        ┌─────────────────┐        ┌─────────────────┐
   │    Web (www)    │        │  iOS Simulator  │        │ Android Device  │
   │ Cloudflare Pages│        │  & App Store    │        │  & Google Play  │
   │ / Netlify / CDN │        │ (Capacitor+SPM) │        │ (Capacitor+AGP) │
   └─────────────────┘        └─────────────────┘        └─────────────────┘
```

## 2. Multi-Platform Strategy & Three.js Flat 2D Pipeline

Instead of maintaining separate codebases in Unity, Flutter, and Web, the project uses **Capacitor 7** with **Three.js (r160)**:

1. **Flat 2D Orthographic Stage in Three.js:** Renders the `1920 × 1080` room artwork on flat 2D planes using an `OrthographicCamera` with zero 2.5D parallax distortion, preserving exact artist framing (`FOCUS` contain/cover blend) and `LinearSRGBColorSpace` + `NoColorSpace` texture pass-through.
2. **Adaptive Character Playback:** Uses GLSL green-screen chroma-key shaders on `<video>` textures on desktop and pre-keyed `.webp` sprite sheets (`uSubUv` uniform) on mobile/touch devices (`LITE`), keeping GPU memory low while interactive chapter videos load.
3. **WebGL Object Silhouette Transitions:** Offscreen `WebGLRenderTarget` pixel readback in `shared.js` extracts the exact silhouette of clicked Three.js object meshes (`passport`, `frame`, `bike`, `rejectOpen`) to mask-zoom into each interactive video chapter.
4. **Instant Web Distribution:** `Capacitor_Apps/app-room/www/` runs directly as a static website and is packaged into `dist_pages/room/` for Cloudflare Pages.

## 3. Native iOS Configuration

- **Package Manager:** Swift Package Manager (`CapApp-SPM`) — avoids CocoaPods completely.
- **Deployment Target:** `IPHONEOS_DEPLOYMENT_TARGET = 16.0`.
- **Bundle Identifier:** `com.likedust.wabtsa` (*We All Breathe the Same Air*).
- **Custom View Controller (`RoomBridgeViewController` in `AppDelegate.swift`):**
  - **Inline Media Playback:** Sets `allowsInlineMediaPlayback = true` on `WKWebViewConfiguration` so videos play inline inside the silhouette mask without iOS fullscreen QuickTime takeover.
  - **Unmuted Autoplay:** Sets `mediaTypesRequiringUserActionForPlayback = []` allowing audio without forced initial tap gates.
  - **Status & Navigation Bar:** Hides status bar and home indicator (`prefersStatusBarHidden = true`, `prefersHomeIndicatorAutoHidden = true`).
  - **Orientation:** Strict landscape locking (`UIInterfaceOrientationMask.landscape`).

---

## 4. Native Android Configuration

- **Application ID:** `com.likedust.wabtsa` (*We All Breathe the Same Air*).
- **Java & Gradle:** Configured with OpenJDK 21 via `android/gradle.properties` (`org.gradle.java.home`).
- **Window & System Bars (`MainActivity.java`):**
  - Sticky immersive mode using `WindowInsetsControllerCompat` to hide navigation and status bars.
  - `#000000` window background in `styles.xml` to prevent white flashes during app launch.
  - `setMediaPlaybackRequiresUserGesture(false)` on `WebSettings` for unmuted video playback.
  - Sensor landscape lock (`sensorLandscape` in `AndroidManifest.xml`).
