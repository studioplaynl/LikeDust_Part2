# Architecture & Technical Overview

**We All Breathe the Same Air** (*Like Dust Part 2*) is an interactive digital video graphic novel designed for seamless delivery across **Web browsers**, **Apple iOS**, and **Google Android**.

```
                           ┌────────────────────────┐
                           │    Single Codebase     │
                           │   (HTML5, Canvas,      │
                           │   Three.js, WebGL)     │
                           └───────────┬────────────┘
                                       │
            ┌──────────────────────────┼──────────────────────────┐
            ▼                          ▼                          ▼
   ┌─────────────────┐        ┌─────────────────┐        ┌─────────────────┐
   │    Web (www)    │        │  iOS Simulator  │        │ Android Device  │
   │ Cloudflare Pages│        │  & App Store    │        │  & Google Play  │
   │ / Netlify / CDN │        │ (Capacitor+SPM) │        │ (Capacitor+AGP) │
   └─────────────────┘        └─────────────────┘        └─────────────────┘
```

## 2. Multi-Platform Strategy & Three.js Flat 2D Pipeline

Instead of maintaining separate codebases in Unity, Flutter, and Web, the project uses **Capacitor 7** with **Three.js (r160)**:

1. **Flat 2D Orthographic Stage in Three.js:** Renders the `1920 × 1080` room artwork on flat 2D planes using an `OrthographicCamera` with zero 2.5D parallax distortion, preserving exact artist framing (`FOCUS` contain/cover blend) and `LinearSRGBColorSpace` + `NoColorSpace` texture pass-through.
2. **Character Sprite-Sheet Playback (`SamPose`):** Renders pre-keyed `.webp` sprite sheets (`standup.webp` for opening Stand-Up & closing Window Gaze, `idle.webp` for Sam's continuous standing Think Pose, and `pigeon.webp` for the ambient Dove) via a custom `uSubUv` GLSL shader, governed by a zero-dependency state machine (`room/shared/fsm.js`).
3. **Clean Fade & Deterministic Audio Handoff (`0.5s` Room Fade-Out → `1.0s` Video Fade-In):** Clicking an unlocked **Chapter Object** (`passport`, `frame`, `bike`, `reject`) transitions `RoomFlow` into `chapterOpening`, plays the object's click SFX (`rustle`, `pickup`, `bell`, `cloth`), cancels all pending room audio timers (footsteps, chirps, chalk, desk letter rustles), and fades out all active room audio (`roomBus` master gain + `amb_room.mp3` + any active foley such as `standup2.mp3`) to `0` over `0.5s` (`500ms`) in lockstep with the black fade-in (`wipe`). Only after the `0.5s` fade completes does `RoomFlow` enter `chapterActive` and start the interactive **Chapter** (`Hoofdstuk_1..4`), whose video audio fades in smoothly over `1.0s` (`1000ms`).
4. **Unified Pre-Room Stage & Mobile Media Handling:**
   - **Synchronous iOS Video Playback:** `www/index.html` embeds `#stage` (`#intro` video + `#scene` airport window) directly so clicking **Start** invokes `iv.play()` synchronously inside the tap handler—avoiding iOS Safari/Chrome autoplay restrictions and eliminating page-transition blips of `#scene`.
   - **Two-Tier Silent Motion on `Doors` ([ADR 0002](adr/0002-two-tier-doors-motion-with-animated-avif-fallback.md)):** Landing `Doors` play muted inline `25fps` H.264 loops (`wa-intro-bg.mp4`, `ld-loop.mp4`) with `preload="auto"`, fading in over static posters (`bgimg`) on `playing` and keeping `<video>` rendered across transient `AbortError`s. When OS policy blocks autoplay with `NotAllowedError` (e.g., iOS Low Power Mode), `<video>` hides immediately (preventing native WebKit play overlays) and swaps to a compact Animated AVIF loop (`wa-intro-bg-fallback.avif` mini-montage, `ld-loop-fallback.avif`), detaching `src` when off-screen or while `#stage` is open to free bitmap RAM.
   - **Safe-Area & Stable First-Tap Framing:** Landing `.doors` sizes to `100svh` (with `html, body { padding: 0 }` and per-panel `env(safe-area-inset-*)` padding, plus `:hover` flex-resizing gated behind `@media (hover: hover) and (pointer: fine)`) so **START** and **ENTER** sit clear of Dynamic Island and iOS Safari's bottom toolbar wake zone and activate `Intro Film` on the very first tap without layout shift; `#stage` (`#introFrame` + `#sceneWrap`, and standalone `intro/index.html`) uses `100dvh` + `fitSceneWrap()` (`stage.clientWidth × stage.clientHeight`) so the airport window hint is never clipped behind Safari's URL bar.
5. **Instant Web Distribution:** `Capacitor_Apps/app-room/www/` runs directly as a static website at root (`/`) and is deployed directly via `Deploy_Cloudflare_Pages.command` (or packaged at root in `dist_pages/` via `build_cloudflare_pages.py`) for Cloudflare Pages (`thesameair.nl`).

## 3. Native iOS Configuration

- **Package Manager:** Swift Package Manager (`CapApp-SPM`) — avoids CocoaPods completely.
- **Deployment Target:** `IPHONEOS_DEPLOYMENT_TARGET = 16.0`.
- **Bundle Identifier:** `com.likedust.wabtsa` (*We All Breathe the Same Air*).
- **Custom View Controller (`RoomBridgeViewController` in `AppDelegate.swift`):**
  - **Inline Media Playback:** Sets `allowsInlineMediaPlayback = true` on `WKWebViewConfiguration` so videos play inline inside the silhouette mask without iOS fullscreen QuickTime takeover.
  - **Unmuted Autoplay:** Sets `mediaTypesRequiringUserActionForPlayback = []` allowing audio without forced initial tap gates.
  - **Status & Navigation Bar:** Hides status bar and home indicator (`prefersStatusBarHidden = true`, `prefersHomeIndicatorAutoHidden = true`).
  - **Orientation:** Strict landscape locking (`UIInterfaceOrientationMask.landscape`).

## 4. Native Android Configuration

- **Application ID:** `com.likedust.wabtsa` (*We All Breathe the Same Air*).
- **Java & Gradle:** Configured with OpenJDK 21 via `android/gradle.properties` (`org.gradle.java.home`).
- **Window & System Bars (`MainActivity.java`):**
  - Sticky immersive mode using `WindowInsetsControllerCompat` to hide navigation and status bars.
  - `#000000` window background in `styles.xml` to prevent white flashes during app launch.
  - `setMediaPlaybackRequiresUserGesture(false)` on `WebSettings` for unmuted video playback.
  - Sensor landscape lock (`sensorLandscape` in `AndroidManifest.xml`).
